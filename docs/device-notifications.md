# Уведомления Calm на устройстве

Раздел «Уведомления» в профиле содержит отдельные переключатели для email и текущего устройства. Включение одного канала не меняет другой. Если Calm установлен на нескольких устройствах, включите push на каждом из них. Для погодных уведомлений нужен выбранный город. Письма с кодом и ссылкой для входа продолжают приходить на почту.

Calm напоминает о продолжающемся приступе через два часа после записанного начала и затем каждые два часа до его завершения. Если сервер был недоступен, он отправляет напоминание за текущий интервал. Утром в 08:00 Calm напоминает пройти ежедневные карточки, если за этот день ещё нет заполненного опроса. Для утра используется часовой пояс выбранного города или `CALM_NOTIF_ZONE`, если город не настроен. При кратком простое утреннее напоминание может прийти до 08:10.

## Сервер

Web Push работает на HTTPS. Локальный Chrome также разрешает проверку через `http://localhost`. Для теста на телефоне используйте HTTPS-адрес, доступный с телефона.

Создайте отдельную пару VAPID один раз. Команда ниже создаёт файл с правами только для владельца и сохраняет ключи без вывода в терминал. Замените контактный адрес на рабочий адрес проекта.

```bash
(
  umask 077
  set -C
  node -e '
    const { createECDH } = require("node:crypto");
    const key = createECDH("prime256v1");
    const encode = value => Buffer.from(value).toString("base64url");
    const publicKey = key.generateKeys();
    const privateKey = Buffer.alloc(32);
    const scalar = key.getPrivateKey();
    scalar.copy(privateKey, 32 - scalar.length);
    console.log("CALM_PUSH_PUBLIC_KEY=" + encode(publicKey));
    console.log("CALM_PUSH_PRIVATE_KEY=" + encode(privateKey));
    console.log("CALM_PUSH_SUBJECT=mailto:calm.notifications.prj@gmail.com");
  ' > ~/.calm-device-push.env
)
```

Внесите эти три строки в локальный или серверный `backend/.env`. Храните файл с ключами вне Git и используйте ту же пару при последующих обновлениях. При замене пары пользователю потребуется заново включить уведомления на устройстве. Выложите обновления frontend и backend и пересоздайте backend, чтобы загрузить переменные.

У погодных уведомлений своё расписание `CALM_NOTIF_CRON` и порог риска из настроек. Их текст на экране блокировки не содержит отметок дневника, уровня риска или города. Напоминания дневника проверяются раз в минуту и ведут к карточкам или разделу приступов. Временные записи попыток рассылки предотвращают дубли по каждому каналу, в том числе при перезапуске backend. При необходимости отключить только напоминания задайте `CALM_REMINDERS_CRON=-`. Подписки, которые push-служба пометила как истёкшие, удаляются автоматически.

## Проверка на устройстве

1. На iPhone с iOS 16.4 и новее добавьте Calm на экран «Домой» и откройте его с иконки. На Android откройте Calm в Chrome или из установленного приложения.
2. Войдите в Calm, укажите город и включите «Уведомления на устройстве». Подтвердите системный запрос. Убедитесь, что после перезагрузки приложения переключатель показывает активную подписку.
3. Оставьте email-уведомления выключенными для проверки независимости. В тестовой среде задайте ближайшее время `CALM_NOTIF_CRON` и подходящий порог прогноза. Закройте Calm и дождитесь уведомления. Нажмите на него, чтобы открыть приложение.
4. Выключите уведомления на одном из двух устройств. Проверьте, что второе сохраняет свою подписку и что состояние email-уведомлений не изменилось.
