# Calm: готовность версии с добровольным участием в общей модели

Область: открытая регистрация; каждый пользователь отдельно решает, передавать ли разрешённые сведения дневника в общий обучающий набор. Участие остаётся добровольным, текущий пилот ограничен взрослыми пользователями из России. Это рабочий список перед переносом на сервер, а не объявление о готовности к массовому запуску.

## Проверено в коде 2026-10-12

- Регистрация создаёт роль `USER` независимо от указанного email; существующие роли `ADMIN` в базе сохраняются. Адрес нормализуется, конфликт при параллельной регистрации обрабатывается. Вход, одноразовая ротация refresh-токена и проверка неактивной сессии покрыты тестами.
- После регистрации создаётся одноразовая ссылка подтверждения email на 24 часа; в базе хранится только хеш токена. Ссылка использует фрагмент URL, токен не попадает в URL API. Повторная отправка ограничена одной попыткой в минуту. При смене email нужен текущий пароль, подтверждение сбрасывается. Погодные письма отправляются только на подтверждённые адреса. Смена пароля отзывает все сессии.
- Отправка писем отделена интерфейсом `EmailService`: доступны SMTP и Resend. Gmail SMTP доставил письмо при локальном LAN-тесте; доставку с будущего VPS ещё проверить. Локальный пароль приложения не переносить на сервер.
- Сервер проверяет порядок начала и конца приступа; при редактировании можно убрать симптомы, триггеры и зоны боли. Проверены CRUD и запрет доступа к чужой записи. Длина заметки и число тегов ограничены. API и MongoDB в варианте закрытого размещения привязаны к loopback; nginx не пропускает клиентский `X-Forwarded-For` в ограничитель запросов.
- Погодный кэш ограничен по размеру; запросы к погоде и почте имеют тайм-ауты. Ежедневная рассылка читает пользователей порциями. Изолированный нагрузочный тест 2026-10-12: 10 параллельных пользователей, 90 секунд, 3 078 запросов без HTTP-ошибок; пик тестовых контейнеров 708 МиБ при одном CPU. Production Compose ограничивает суммарную память контейнеров 2,25 ГиБ на VPS с 4 ГиБ RAM; MongoDB получила лимит 1 ГиБ после пика 463 МиБ в тесте с лимитом 512 МиБ. Тест не заменяет проверку на сервере и более длительный прогон.
- Конвейер общей модели повторно проверен на изолированных синтетических данных: экспорт 300 размеченных дней 30 участников, отзыв до 290/29, восстановление и очистка старых артефактов. Кандидат остаётся офлайн и не включается автоматически. Этот тест подтверждает механику, а не качество прогноза на людях.

## Что остаётся перед открытием участия

1. VPS куплен: Ubuntu 24.04.4 LTS, 1 vCPU, 4 ГиБ RAM, 45 ГБ NVMe. Docker 29.1.3 и Compose 2.40.3 установлены; UFW разрешает только входящие 22/80/443. Домен `peaceofmindforyourhead.duckdns.org` уже разрешается в IPv4 VPS `193.23.195.216`. Сайт ещё не развернут.
2. Production Compose запускает Caddy как reverse proxy с автоматическим HTTPS Let's Encrypt. MongoDB, backend и frontend не публикуют порты; снаружи опубликованы только Caddy 80/443. Проверить фактическое получение и автоматическое продление сертификата после запуска.
3. Создать на сервере новые уникальные секреты (JWT, MongoDB роли, HMAC, SMTP), не копируя локальные значения. Отслеживаемые файлы проверены на распространённые форматы ключей; `.env` локально игнорируются Git и имеют режим `600`. Ранее показанные почтовые учётные данные нужно отозвать у провайдеров; это требует входа владельца в Google/Resend. Gmail App Password вводить заново скрытым локальным скриптом.
4. Перенести существующую базу двух участников и аватары с Mac на VPS через проверенный backup/restore, не создавать пустую production-базу. Настроить обратное копирование MongoDB и аватаров на Mac по SSH и проверку восстановления. Пользователь принимает локальное хранение копий без шифрования на диске; передача по SSH шифруется. Удалённый backup не сработает, пока Mac недоступен.
5. Проверить регистрацию, вход, подтверждение email, смену пароля, CRUD дневника, изоляцию данных чужих пользователей, доставку писем и нагрузку на VPS. Закрыть наружу всё, кроме веб-портов и административного SSH.
6. Согласие текущей версии `shared-model-pilot-v1` явно утверждено пользователем 2026-10-12 для этого пилота; backend и worker используют совпадающие версию и digest. Это снимает внутренний технический gate на согласие, но не является отдельной юридической экспертизой. После проверки VPS можно открыть набор; worker уже собирает только явные согласия и подходящие прогнозы/исходы.

Двухфакторная аутентификация ещё не реализована. Текущие отдельные почтовый сервис, сессии и подтверждение адреса позволяют добавить её следующим этапом; до этого нельзя обещать 2FA пользователям.

## Обязательные проверки перед открытием участия

| Требование | Статус на 2026-10-12 | Что подтверждено / что нужно сделать |
|---|---|---|
| MongoDB защищена паролем и не доступна из интернета | Сервер подготовлен, production MongoDB ещё не запущена | Локально проверены `--auth` и отдельные роли приложения/worker; production Compose не публикует Mongo-порт и включает `--auth`. На сервере ещё создать уникальные роли, восстановить данные и проверить соединение только через аутентификацию. |
| Нельзя читать чужой дневник через API | Проверено для основных записей | HTTP-интеграционный тест создаёт двух пользователей; второй получает `404` на приступ и лекарство первого, а его статистика не содержит чужой приступ. До сервера повторить проверку на полном контуре и пройти остальные приватные endpoint-ы. |
| Секреты не хранятся в Git и не попадают в логи | Код и текущие файлы проверены; ротация частичная | `backend/.env` исключён из Git. Единственный отслеживаемый `frontend/.env` содержит только `VITE_API_URL`, публичный адрес API. Убраны email-адреса, темы писем и часть API-ключа из журналов почты; удалены email пользователя из журнала удаления аккаунта и ошибок рассылки. Локальный JWT-секрет заменён, `backend/.env` выставлен в режим `600`. Ранее в выводе команды Compose были показаны значения переменных окружения; Resend/SMTP учётные данные нужно отозвать в панели почтового провайдера до пилота. |
| HTTPS настроен и проверен | Не выполнено: DNS настроен, production proxy ещё не запущен | Caddy в production Compose автоматически запрашивает и продлевает Let's Encrypt сертификат для `peaceofmindforyourhead.duckdns.org`. Проверить публичный HTTPS после запуска. |
| Приглашение и одобрение аккаунтов | Не требуется по выбранному сценарию | Регистрация остаётся открытой без кодов приглашения; каждый пользователь может отдельно согласиться или продолжить без участия. Администратор может заблокировать участие конкретного пользователя, что отзывает его активное участие и запрещает повторное согласие до разблокировки. Это не блокирует вход в приложение. После блокировки обучающая выборка исключит пользователя при следующей пересборке worker. |
| Резервная копия восстанавливается | Локальная копия на Mac проверена; серверную передачу настроить | Пользователь выбрал копии на собственном Mac. Настроить их получение с VPS по SSH и проверить восстановление именно с полученной копии. Отдельное облачное хранилище и шифрование на диске пользователь не требует; потеря/недоступность Mac оставляет сервер без независимой копии. |

Интеграционные тесты после обновления: `mvn -q -Dtest=FirstReleaseFlowTest test` завершился успешно; `bash backend/scripts/run-shared-risk-migration-test.sh` завершился успешно на синтетической базе, тестовые контейнеры и том удалены. Текущая локальная MongoDB и данные пользователя этими тестами не менялись. `frontend/.env` — публичная настройка адреса API, её нельзя использовать для секретов.

Для общей модели реализован первый входной экран согласия: он появляется, когда набор открыт и у пользователя нет решения по текущему тексту. Выбор «Продолжить без участия» фиксируется отдельным событием `DECLINED`, остаётся возможность подключиться позже в профиле; смена версии или отпечатка условий снова требует решения. Экран читает действующий текст и версию с API. Администратор может заблокировать участие пользователя; разблокировка не включает его автоматически, потребуется новое согласие. На 2026-10-12 локально открыты enrollment и worker для проверки: worker создал пустое поколение (0 активных согласий и 0 подходящих записей). Внешний набор закрыт.
